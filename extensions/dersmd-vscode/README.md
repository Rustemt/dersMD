# DersMD VS Code

`ders.json` kurs paketlerini doğrular.

## Kurulum (geliştirme)

```bash
cd extensions/dersmd-vscode
npm install
npm run compile
```

VS Code’da **Run Extension** (F5) veya:

1. Extensions → Install from VSIX (paketledikten sonra)
2. Komut paleti: **DersMD: Paketi Doğrula**

`content/courses/*.json` için JSON şema önerileri de gelir.
